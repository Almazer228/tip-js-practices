## Организация кода

В приложении используется разделение ответственности между модулями:

- `task-service.js` — создание, поиск, изменение и удаление задач.
- `form-validation.js` — проверка данных, введённых пользователем.
- `task-storage.js` — сохранение, загрузка и удаление данных из `localStorage`.
- `task-view.js` — создание карточек задач и отображение информации на странице.
- `main.js` — взаимодействие между модулями и обработка действий пользователя.
- `task-selectors.js` — фильтрация и получение нужных наборов задач.
- `data.js` — исходные данные приложения.

Объект `storage` передаётся функциям хранения через параметры. Это позволяет использовать функции с разными хранилищами и проверять их независимо от браузера.

Данные из JSON проверяются перед использованием, поскольку сохранённая информация может иметь неправильную структуру или быть повреждённой.

## Проверка восстановления и ошибок

| Случай | Ожидание | Фактический результат | Итог |
|---|---|---|---|
| Записи нет | Используется независимая копия исходного набора | Предусмотрено в `loadTasks()` | Отдельно не проверялось |
| Корректная запись | Данные восстанавливаются после перезагрузки | Предусмотрено в `loadTasks()` | Отдельно не проверялось |
| Повреждённый JSON | Приложение запускается с исходным набором и предупреждением | Ошибка обрабатывается через `try/catch` | Отдельно не проверялось |

| Сброс | Удаляется только ключ текущего набора | Используется `removeSavedTasks()` | Отдельно не проверялось |
| Общий и индивидуальный наборы | Изменения не смешиваются | Для наборов предусмотрены отдельные ключи хранения | Отдельно не проверялось |
